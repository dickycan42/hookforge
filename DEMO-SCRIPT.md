## Shot 1 — Cold open (0:00–0:15)
- **Visual:** HookForge landing, dark UI. Cursor in topic input.
- **VO:** "Every faceless creator has the same problem: hooks, scripts, captions —
  every day, every platform. HookForge does all three in seconds."
- **Action:** Type topic: `octopus has three hearts` → hit Enter.

## Shot 2 — Hook generation + gate (0:15–0:55)
- **Visual:** 5 hooks stream in, each labeled with its framework
  (curiosity gap, contrarian, callout, cold-open, stakes).
- **VO:** "Five hooks, five frameworks. But here's the Frankenstein part — every
  hook passes through a four-check quality gate: no topic reveal in the first
  two seconds, answer withheld, open loop, conversational tone."
- **Action:** Point to gate score header `X-HookForge-Gate: 5/5`. Click one
  failing hook example (if shown) → `[needs review]` flag.

## Shot 3 — Script builder (0:55–1:30)
- **Visual:** Switch to Script tab. Select 30s, English. Script streams with
  [HOOK] / [BODY] / [CLIFFHANGER] beat markers.
- **VO:** "One click turns the winning hook into a full narration script —
  TTS-friendly punctuation, paced beats, cliffhanger ending."

## Shot 4 — Caption composer (1:30–1:55)
- **Visual:** Switch to Caption tab. Platform selector: X. Caption appears,
  character counter shows ≤ 280.
- **VO:** "And a caption that respects each platform's limits — X under 280,

- **Visual:** Type a topic used before (e.g. `octopus`). Amber banner appears:

- **VO:** "HookForge stitches four technologies that don't belong together —

- **End card:** hookforge.vercel.app · github.com/dickycan42/hookforge ·
